# GitFlow Test

Ce projet est utilisé pour **tester le flux GitFlow** :  
- Branches : main, develop, feature/*, release/*, hotfix/*  
- Commits : test feature et hotfix  
- PR → develop → squash merge → back-merge → tag

## Test feature

Cette section permet de vérifier que les commits sur une feature branch sont bien pris en compte.

## Test hotfix

Cette section permet de tester le workflow d’une hotfix branch.
